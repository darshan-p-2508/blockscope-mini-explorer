# Changelog

## [0.1.0] - 2026-10-10

### Added
- Initial educational blockchain and proof-of-work core.
- Local explorer dashboard and JSON HTTP API.
- Transaction queue, mining reward, balances, and chain validation.
- Automated unit tests and foundational project documentation.

### Known limitations
- In-memory state only.
- Demo account labels are not cryptographic wallets.
- No peer-to-peer networking or public-chain integration.
